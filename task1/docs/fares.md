# 운임 규칙

## 거리 운임

- 기본운임 1,450원: 10km까지
- 10km 초과 ~ 50km까지: 5km마다 100원 추가
- 50km 초과: 8km마다 100원 추가 (50km까지의 추가분 800원은 그대로)
- "까지"는 그 값을 포함한다
  - 10.0km → 1,450원
  - 15.0km → 1,550원
  - 15.1km → 1,650원
- 모자란 구간도 한 구간으로 친다 (10.1km → 1구간)

## 승객 유형

| 유형 | 코드 | 할인 |
|---|---|---|
| 어른 | `adult` | 없음 |
| 청소년 | `youth` | 기본운임 20% |
| 어린이 | `child` | 기본운임 50% |
| 경로 | `senior` | 전액 무료 |

- 할인은 **기본운임에만** 적용한다. 거리 추가운임은 할인하지 않는다
- 할인한 뒤 10원 미만은 버린다
- 경로는 거리와 상관없이 0원
- 모르는 유형은 오류를 던진다
