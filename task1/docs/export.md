# 이용내역 CSV

`toCsv(settle 결과)` → 문자열

## 형식

- 첫 줄 머리글: `일시,승차역,하차역,거리,요금,환승`
- 승차마다 한 줄, 정산 결과 순서대로
- 마지막 줄: `합계,,,<거리 합계>,<요금 합계>,`
- 줄바꿈은 `\n`, 마지막 줄 뒤에도 `\n`

## 열

| 열 | 값 |
|---|---|
| 일시 | 승차 시각 `YYYY-MM-DD HH:mm` |
| 승차역 · 하차역 | 역 이름 그대로 |
| 거리 | 소수 첫째 자리 고정 (`12.0`) |
| 요금 | 숫자만 (쉼표 없음) |
| 환승 | 환승 승차 `Y`, 아니면 `N` |

- 합계 줄의 거리도 소수 첫째 자리 고정

## 이스케이프

- 값에 쉼표 `,` · 큰따옴표 `"` · 줄바꿈이 있으면 큰따옴표로 감싼다
- 안의 큰따옴표는 두 번 쓴다 (`"` → `""`)
- 역 이름에 쉼표 · 큰따옴표가 들어간 역이 있다
