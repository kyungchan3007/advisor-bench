# 과제: 막차 러너 풀이기

막차 러너는 승객을 열차 · 개찰구 · 거리를 지나 목적지 출구까지 보내는 격자 게임입니다. 규칙은 `docs/rules.md`에 있습니다.

레벨 하나를 받아 **가장 좋은 풀이**(규칙 6장)의 행동 문자열을 출력하는 프로그램 `solver.js`를 만들어 주세요.

```bash
node solver.js levels/01-sample.json
```

- 표준 출력에 행동 문자열 한 줄만 출력 (도착할 수 없으면 `불가`)
- 레벨당 **10초** 안에 끝나야 합니다
- Node 22 기본 기능만, 의존성 추가 없이
- 채점은 공개하지 않은 레벨 여러 개로 하고, 출력이 정답 문자열과 **정확히 같아야** 맞습니다
  - 숨은 레벨은 `levels/`보다 훨씬 크고(최대 약 61×113칸, 노선 30개 안팎, `maxTick` 400) 함정이 있을 수 있습니다
- `levels/`에 예시 레벨과 정답(`levels/answers.json`)이 있습니다
- 판정 코드는 주지 않습니다. 규칙 문서를 꼼꼼히 읽어 주세요
- 다 되면 접근 방법을 짧게 정리해 주세요
